This bootstrap package includes unmodified command-line components from 7-Zip 26.02.

additional restriction. Copyright and license details are available from:

https://www.7-zip.org/license.txt
https://www.7-zip.org/

The corresponding source code can be obtained from the official 7-Zip site:

https://www.7-zip.org/download.html

Bundled files:

- windows-x64/7za.exe: official x64 standalone Windows console executable from 7-Zip Extra
- linux-x64/7zz: official Linux x86-64 console executable
- macos-x64/7zz: official universal macOS console executable
- macos-arm64/7zz: official universal macOS console executable
